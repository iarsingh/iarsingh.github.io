Featured project

Production MLOps Platform on Kubernetes

Train, govern, serve, deploy and observe an ML model the way production teams need it — not just in a notebook.

Problem
Getting a model accurate is the easy part. Teams struggle with reproducibility, knowing which model version is live, rolling back a bad model quickly, and seeing when predictions degrade.
Solution
A churn classifier trained and versioned in MLflow, promoted by an evaluation gate, served by a FastAPI API on Kubernetes, shipped through GitHub Actions and observed with Prometheus and Grafana.
Engineering decisions
  • Model served by registry alias (@champion) — rollback is an atomic alias move plus /reload, no redeploy.
  • Readiness returns 503 until a model loads, so pods never crash-loop when MLflow is down.
  • helm upgrade --atomic auto-reverts failed rollouts; deploys are environment-gated.
  • Keyless GCP auth via Workload Identity Federation; restricted PSS and default-deny NetworkPolicies.
  • Spot training pool that scales to zero; HPA-sized inference to pay for load actually served.
Deployment
Terraform for Artifact Registry, GCS and a GKE spot node pool; Helm chart with probes, HPA, PDB and ServiceMonitor; CI runs ruff, pytest, helm lint, terraform validate and Trivy scans.
Outcome & learning
A reproducible reference that runs locally with Docker Compose and validates in CI. It is infrastructure-as-code, not a hosted demo — the cloud steps target your own GCP project.
